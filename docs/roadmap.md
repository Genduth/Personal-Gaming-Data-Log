# Roadmap

## Next

- Playnite Data Exporter importer for multi-launcher PC libraries
- Admin page or Power BI write-back companion for resolving unmatched executables
- RetroAchievements provider
- Automatic stale-session reconciliation with an explicit audit trail
- PostgreSQL read-only role bootstrap command

## Later

- Fabric Eventstream/Eventhouse sink for sub-minute Power BI refresh
- Xbox and PlayStation import adapters using supported account exports or APIs
- Discord Rich Presence publisher driven by the same collector state
- Personal goals: backlog, completion targets, monthly playtime budget and “finish before buying” view
- Game recommendation model based on unfinished games, recent genres and typical session length
- Shareable annual “gaming wrapped” report with privacy-safe export

## Ideas worth experimenting with

- A “context switching” score based on how often games change within an evening
- Cost per played hour using an optional purchase-price field
- Backlog decay: owned games that have never been launched or have gone dormant
- Achievement velocity and hardest-unlock gallery
- Mood or rating notes attached after a session
- Controller/keyboard, handheld/desktop and solo/co-op dimensions
